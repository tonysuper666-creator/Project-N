# 一、长期愿景

## 1. 项目愿景
本项目是一款以科幻/军事世界观为背景的在线 FPS 刷宝游戏（looter-shooter），面向浏览器，采用赛季制运营。
游戏强调射击手感、装备成长、关卡挑战和持续更新内容，让玩家在长期游玩中不断获得新的探索目标与战斗动力。

## 2. 核心定位
“科幻题材的网络刷宝射击游戏”——融合快速直接的 FPS 战斗体验，与长期养成、重复挑战、装备收集和内容迭代的网游结构。

## 3. 世界观概述
近未来，人类向未知前线区域持续扩张，在各类危险地带发现失落技术、异常区域、废弃设施与高价值资源。
这些区域并不稳定、会随时间变化，因此每个赛季可作为一次世界事件，带来新的地图、副本、敌人与剧情线索。

## 4. 玩家身份
玩家扮演前线探险者 / 回收人员 / 合同制行动员，进入高危区域执行任务：回收资源、争夺装备、调查异常，并在不断升级的敌对环境中生存。

## 5. 核心玩法循环
围绕“进入 → 战斗 → 获取 → 强化 → 再挑战”：
进入副本 → 清理敌人 → 获取装备与材料 → 完成目标 → 返回撤离结算 → 强化角色与武器 → 挑战更高难度内容。

## 6. 赛季制理念
采用赛季制内容更新，每季推出新装备、地图、副本、Boss、敌人与剧情碎片。赛季是世界事件的一部分，是推动玩家回归与持续成长的主要动力。

## 7. 内容更新方向
新装备 / 新地图 / 新副本 / 新敌人 / 新 Boss / 新剧情碎片 / 新玩法机制。

## 8. 风格与氛围
科幻、未知、前线、紧张、探索感；既有冒险发现的兴奋，也保留高风险环境的压迫与危机感。

# 二、当前已实现的设计（现状快照）

## 10. 技术形态与运行方式
- **引擎/技术栈**：**Three.js (r0.160) + 原生 JavaScript（ES Module，importmap，无构建步骤）**。不是传统游戏引擎，全部逻辑手写。
- **运行方式**：**浏览器打开网页即玩**，静态文件直接托管，零安装。
- **目录**：`test/`＝开发原型（`test/src/*.js` 是主源码），`final/`＝对外镜像；两者内容保持同步。
- **账号**：本地账号系统（localStorage 存档），无服务器、离线可玩；存装备、金币、等级、任务、武器强化等级。

## 11. 基地 → 部署 → 撤离 的单局结构
- **基地/训练场**：安全区，备用弹无限。内含三个交互点：**任务官**（接/交任务）、**部署门**（选副本出击）、**商人**（军械/强化/补给）。
- **副本**：线性推进，沿途分段刷更强的敌人；每段有**铁门**拦路，清空当段敌人后开启。
- **撤离**：击败副本尽头的 Boss 后，在 **Boss 所在处生成撤离点**，走上去 [E] 结算收获。

## 12. 地图 / 副本
两张独立副本，靠**极远的 X 轴偏移**放在同一场景里互不干扰（伦敦 X≈260，巴黎 X≈3000；武器射程 ≤340 « 两图间距，玩家被夹在当前区域内）。

- **伦敦沦陷（Lv.1，普通）**：伦敦街区线性推进，5 段关卡（街口→商业街→广场→议会前→大本钟），尽头 Boss「钢铁首领」(HP 4200)。大本钟、红色电话亭、地铁标、巴士等地标。
- **巴黎攻防（Lv.3，高危）**：**曲折/折线路线**（6 点路径、5 段、含 90° 拐弯），占地约伦敦的 5 倍。穿过**凯旋门**（从下方通过）、绕过**环岛广场**、沿**塞纳河 + 桥**推进，尽头**埃菲尔铁塔**前迎战 Boss「铁塔守卫者」(HP 6000)。**火箭筒 / 连发火箭筒为本图专属掉落**。
- **关键技术**：用「分段并集碰撞」(`clampToArea`) 让玩家在平地上沿直角转弯行走；关卡按路径点触发（`triggerPt/spawnPt/bossPt`）；铁门朝向自适应。玩家地面锁定 y=0（无可行走高低差），“层次感”靠结构布局（凯旋门、环岛、拐弯）表达。
- **天空特效**：漂移的云朵 Sprite + 太阳，随地图重新着色。

## 13. 武器系统
统一的武器定义驱动：`mode`（auto/semi/melee）、伤害、射速、弹匣、后坐、射程等。
- **AK-47（默认步枪）**、**制式手枪**、**作战匕首**（近战）。
- **原型冲锋枪**：高射速低伤。
- **激光步枪**：**真·持续光束**（按住持续造成 DPS + 耗弹），跳伤害数字。
- **加特林**：**逐渐提高转速**（spin-up），100 发大弹匣，换弹慢。
- **反器材狙击枪**：右键开镜（窄 FOV + 准星），单发巨伤、爆头秒杀。
- **激光狙击枪（联狙）**：开镜、按住约 4 发/秒瞬发光束，**具备穿透**（一条线上穿多个敌人，遇实体才停）。
- **火箭筒**：单发爆炸投射物，高 AOE、弹速快下坠少（巴黎专属）。
- **连发火箭筒**：连发、弹速慢下坠大，靠数量覆盖（巴黎专属）。
- **命中系统**：射线命中 + 每部位不同伤害倍率（头 2.5 / 胸 1.3 / 身 1.0 / 臂 0.7 / 腿 0.65）。

## 14. 武器强化系统（养成核心）
所有武器**初始为「普通」**，通过强化**部位**提升数值与稀有度；强化材料来自**地图掉落**，每次强化有**成功率**（越高级越低），失败消耗材料不升级。
- **弹匣**（容量）→ 升到**稀有**
- **枪芯**（伤害）→ 升到**史诗**
- **枪管**（射速）/ **枪口**（后坐力）/ **枪托**（画面稳定）→ 升到**传说**
- 武器最终稀有度 = 已强化部位里的**最高档**。
- 材料：**强化模块**（稀有，用于弹匣/枪管/枪口/枪托）、**武器核心**（史诗，用于枪芯）。
- 数值折算：不污染基础定义，装备时实时合成「有效武器」。UI 在商人处，含武器选择、实时数值总览、材料图标、成功率。

## 15. 护甲 / 装备 / 掉落
- **护甲等级**（单护甲槽，减伤递增）：战术背心 12% → 作战头盔 18% → 防弹背心 24% → 纳米护甲 32% → **动力装甲 45%（+20 生命上限，传说）**。
- **装备/gear**（换弹加速）：战术手套 +15% → 战术背包 +25% → **外骨骼框架 +38%（传说）**。
- **掉落表**分图：伦敦（步枪/狙击/激光/护甲/强化材料），巴黎更肥（含火箭筒专属、传说护甲/装备）。
- **复活币**：阵亡自动消耗一枚原地满血复活，可在商人处兑换。

## 16. 敌人设计
- **两个 CC0 物种混编增加多样性**：**士兵**（Soldier，含程序化战术护具、随机配色）+ **战斗机器人**（RobotExpressive，动画映射到统一 Idle/Walk/Run）。机器人偏向高级 tier，士兵偏近战冲锋。
- **分级 tier**：小兵 / 精英(蓝) / 重装精英(紫) / 重型(红) / 首领(金，2.4× 体型)，各有血量、伤害、移速、体型倍率。
- **行为**：以**近战为主**，逼近后触发**前冲挥砍动画**；Boss 更快更高血。
- Boss 战有**顶部血条**（跑远不消失）。

## 17. 经济与进度
- **金币**（击杀/清关/任务奖励，商人消费）、**经验/等级**（提升生命上限）、**任务系统**（击杀/精英/收集/波次/Boss 目标，回任务官领奖）。
- 掉落物走上去自动拾取进背包；单局结束有**撤离结算**（击杀、波次、金币、经验、战利品）。

## 18. 美术与资源策略（重要约束）
- **只用 CC0 / 免费授权 或 原创程序化生成的资源**（真实伦敦/巴黎地标照片无法抓取嵌入，改用 CC0 照片贴图）。
- **贴图**：Poly Haven CC0 照片级贴图（沥青、砖墙、鹅卵石、石灰岩、屋瓦等）。
- **枪械模型**：Kenney「Blaster Kit」**CC0**，每把武器一个独立模型，运行时自动归一化朝向。
- **角色模型**：three.js CC0 示例（Soldier / RobotExpressive）。
- 所有署名记录在 `docs/CREDITS.md`。

## 19. 技术架构要点
- 双地图 X 偏移隔离；分段并集碰撞 `clampToArea`；路径感知关卡 + 朝向自适应铁门。
- 第一人称 viewmodel 独立相机+清深度渲染（枪不穿墙）；按武器加载 GLB。
- 火箭为真投射物（重力 + 逐帧射线检测 + `explodeAt` AOE）；激光穿透用排序命中去重。
- 账号/背包/强化数据本地持久化，装备变更即时同步到武器系统（`applyLoadout`）。

# 三、路线决策与权衡

## 20. 引擎选择：为什么现在用 Three.js
- **核心优势 = 网页即玩、秒开、零安装、发链接就能分享**，这是当前最看重的点。
- 代价：画质与大型 3D 生态不如专业引擎；但对本作这种**竞技场式 looter-shooter FPS 体量完全够用**。
- 结论：**只要目标还是「网页轻量分享」，就继续 Three.js**，不为「以后可能换引擎」而现在折腾迁移。

## 21. 未来可能的引擎迁移（备忘，非当前计划）
- **跨引擎代码不能直接迁移**，无论转 Godot 还是虚幻都要重写引擎相关代码。真正**保值的是**：游戏设计与数值、美术资源（CC0 的 .glb/贴图，各引擎都能导入）、开发经验。
- **Godot**：免费开源、上手快、FPS 该有的系统齐全，且「节点树/编辑器工作流」与虚幻相近——是从 Three.js 出发**最平滑、性价比最高**的升级目标（能导出桌面/手机/主机，网页导出是附赠、较重）。
- **Unreal**：顶级画质/大规模才需要，学习曲线陡、吃硬件；对本作体量属“杀鸡用牛刀”。
- **策略**：现在把**设计、数值、关卡、美术**这些保值资产做扎实；真正确定要升级画质/上架时，再一步到位跳 Godot 或虚幻，中间少做一次重写。

## 22. 开发工具
- 仓库已接入 **Claude-Code-Game-Studios** 模板（`.claude/`：49 agent / 73 skill / hook / 规则），用于流程化协作（策划、关卡、code-review、平衡检查等）。其中 Godot/Unity/Unreal 专属 agent 对当前 Three.js 项目暂不使用，保留备未来迁移。
